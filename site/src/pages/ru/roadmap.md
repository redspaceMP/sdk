# Дорожная карта

RedSpace SDK развивается вместе со скриптовым хостом платформы. **Ядро сервера
закрыто и поставляется отдельно**; ниже милстоуны изложены с точки зрения
публичного SDK.

Дуга платформы одной строкой:

```
транспорт → скриптовый хост → голос → ассеты → gateway → анти-чит → 1000 игроков
```

## M0 — Фундамент ✅

- Фундамент Rust-ядра (конфиг, протокол, упаковка ресурсов, метрики, HTTP
  админ-поверхность, БД, CLI).
- **Этот SDK**: созданы и протестированы `@redspacem/server-types` и
  `@redspacem/rpc` (16 тестов), настроены Bun workspace + Biome + CI.

## M1 — Транспорт

Настоящий сетевой слой на QUIC: handshake, ping/pong, каркас соединений,
метрики. С точки зрения SDK: пока ничего не меняется — ресурсы продолжают
работать с типизированным контрактом `mp.*`.

## M2 — Укрепление транспорта

Более полный QUIC-слой: auth-флоу, re-connect, backpressure.

## M3 — Симуляция мира

ECS-мир, spatial grid, синк Player/Vehicle (snapshot + delta), interest
management. Поверхности `mp.players` / `mp.vehicles` в
`@redspacem/server-types` начинают отображать живые данные симуляции.

## M4 — Скриптовый хост ⭐

Ядро исполняет TypeScript-ресурсы (на базе QuickJS). **Именно на этот момент
нацелен SDK**: логика гейммода переходит полностью на TypeScript, ресурсы
упаковываются в проверяемые подписанные бандлы.

- `mp.*` становится реальным в рантайме (сегодня это типизированный контракт
  + моки).
- `@redspacem/rpc` привязывается к RPC-каналу хоста.
- Пример freeroam становится запускаемым гейммодом.

## M5 — Персистентность

Аккаунты/персонажи, save/load, presence. На стороне SDK: паттерны и хелперы
для сохранения/загрузки данных игрока.

## M6 — Голос и ассеты

Opus-голос (jitter, микширование) и стриминг ассетов (S3/MinIO) с дисковым
кэшем. На стороне SDK: типизированные привязки для голосовых каналов и
загрузки ассетов, а также поверхности `browser-types` для игрового UI,
использующего стриминговые ассеты.

## M7 — Gateway и платформенная шина

Master server (браузер серверов), Telegram-логин, лаунчер-API, плюс шина NATS
JetStream (heartbeat, глобальный чат). На стороне SDK: типизированные клиенты
для gateway API.

## M8 — Анти-чит и масштаб

Полная анти-чит валидация плюс стресс-тесты на 200→1000 игроков. На стороне
SDK: хуки для отчётов и обработки анти-чит событий.

## M9 — Полный набор RP-ресурсов

Платформа поставляет полный набор roleplay-ресурсов.

## M10+ — Клиент и UI

RED4ext-бридж (игровой клиентский плагин), кастомные карты, CEF UI,
платформенный хостинг. `@redspacem/client-types` и `@redspacem/browser-types`
полностью реализуются на этом этапе.

---

Ничто здесь не является обещанием или обязательством — график ядра ведётся
внутри (закрытого) серверного проекта. SDK остаётся **контракт-первым**: по мере
появления возможностей хоста SDK добавляет для них типизированную поверхность,
всегда с моками, чтобы разработчики гейммодов могли создавать и тестировать
впереди хоста.
